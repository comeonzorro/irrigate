### Description
```
Irrigate vous aide à concevoir votre potager comme un pro — sans être agronome.

Définissez votre parcelle (largeur, longueur, exposition), indiquez votre code postal et choisissez vos cultures adaptées à votre climat : Bretagne, Île-de-France, Normandie, Occitanie… L’option serre ou tunnel débloque tomates, poivrons, melons et autres variétés exigeantes dans les régions plus fraîches.

FONCTIONNALITÉS
• Plan 2D interactif avec cultures, bandes par espèce et réseau d’irrigation
• Vue 3D pour visualiser tuyaux, goutteurs, vannes et arrosage enterré
• Catalogue régional de variétés (fraisiers, tomates, courgettes, salades…)
• Modes d’arrosage : goutte-à-goutte enterré ou surface, aspersion, tuyau, arrosoir
• Estimations d’eau (jour / semaine / mois), rendement kg et valeur €
• Recommandations de produits (irrigation, semences, engrais) selon votre projet
• Conseils de répartition si la parcelle est trop petite pour vos cultures

POUR QUI ?
Jardiniers amateurs, potagers familiaux, locavores et bricoleurs qui veulent anticiper l’installation avant d’acheter le matériel en magasin.

IMPORTANT
Les résultats sont des simulations indicatives. Irrigate ne remplace pas un conseil professionnel ni la conformité de votre installation (eau, pression, normes locales). Consultez un installateur pour le raccordement définitif.

Site : irrigate.fr · Assistance : irrigate.fr/assistance
Contact : contact@irrigate.fr
```

## Confidentialité de l’app (questionnaire Apple)

Réponses recommandées pour v1.0 (pas de compte, API stateless) :

1. **Collectez-vous des données ?** Oui  
2. **Types de données :**
   - **Coordonnées** : Non (pas d’email sans contact volontaire hors app)
   - **Localisation** : Non (code postal saisi ≠ GPS ; ne pas cocher « position précise »)
   - **Autres données utilisateur** : Oui → **Autres données** → contenu saisi (dimensions parcelle, cultures) — **Non liées à l’identité**, **Non utilisées pour le suivi**, finalité **Fonctionnalité de l’app**
   - **Données d’utilisation** : Optionnel — logs techniques hébergeur uniquement ; si demandé : **Diagnostics** liés à la performance, non liés à l’identité
3. **Suivi (tracking)** : Non  
4. **Données liées à vous** : Non (pas de compte)
